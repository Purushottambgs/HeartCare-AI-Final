  • Source: Cardiovascular Disease Dataset

  • Age range: 29–65 years
  • Pre-processing: outlier removal, BMI capping

  • n_estimators: 300

🔬 ECG Model
  • 20 signal features extracted per image
  • Features: time-domain + frequency-domain
  • Peak detection: SciPy find_peaks
  • FFT-based LF/HF ratio analysis
  • Spectral entropy for arrhythmia detection
  • Trained on synthetic + augmented ECG images
🔌 REST API Reference
Use these endpoints to integrate HeartCare AI into external applications.
POST /api/predict
Predict cardiovascular risk from patient vitals. Returns probability, risk level, SHAP attribution, and recommendations.
Request Body (JSON):
{
  "age": 55, "gender": 1, "height": 165, "weight": 80,
  "ap_hi": 140, "ap_lo": 90, "cholesterol": 2,
  "gluc": 1, "smoke": 0, "alco": 0, "active": 1,
  "patient_name": "Ramesh Kumar"
}
POST /api/ecg
Analyse an ECG image. Send as multipart/form-data with key ecg_image.
Returns:
{
  "result_label": "Normal Pattern",
  "pattern": "normal",
  "confidence": 91.2,
  "features": { ... 20 metrics ... },
  "screening_note": "AI screening only"
}
GET /api/history
Fetch prediction history. Query params: limit, risk, search.
Example:
GET /api/history?limit=10&risk=High+Risk

{
  "total": 10,
  "records": [ ... ],
  "ecg_total": 5,
  "ecg_records": [ ... ]
}
GET /api/dashboard
Returns aggregate statistics: total predictions, risk distribution, BMI breakdown, ECG counts, trend data.
⚠ Authentication Note
All API endpoints are accessible without a token for demo purposes. In production, add token-based authentication (JWT/API key) before deploying publicly.
⚠ Medical Disclaimer
HeartCare AI is an educational and research prototype. It is not a certified medical device. Predictions are based on statistical models and should not replace professional clinical diagnosis. Always consult a qualified cardiologist for medical decisions.
