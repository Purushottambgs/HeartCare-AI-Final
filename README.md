# ❤️ HeartCare AI

## Intelligent Heart Disease Prediction System Using Machine Learning

HeartCare AI is an AI-powered healthcare platform designed to assist in the early prediction of cardiovascular disease risk using Machine Learning, ECG Analysis, Explainable AI, and Healthcare Analytics.

The system combines clinical parameters, ECG image analysis, interactive dashboards, and AI-driven recommendations to support preventive healthcare and improve cardiovascular risk assessment.

---

## 🚀 Key Features

### 🧠 AI-Based Heart Disease Prediction
- Cardiovascular risk prediction using Machine Learning
- XGBoost-based classification model
- Risk categorization:
  - Low Risk
  - Moderate Risk
  - High Risk
  - Critical Risk

### ❤️ ECG Analysis Module
- ECG image upload support
- ECG preprocessing using OpenCV
- Waveform analysis
- Cardiac abnormality screening

### 🔍 Explainable AI (SHAP)
- Feature contribution analysis
- Transparent predictions
- Identification of major risk factors

### 📊 Interactive Dashboard
- Prediction analytics
- Health monitoring
- Risk visualization
- User history tracking

### 🩺 Doctor Recommendation System
- Nearby hospital locator
- Cardiologist recommendations
- Healthcare accessibility support

### 🔄 What-If Risk Simulation
- Modify health parameters
- Observe risk changes dynamically
- Preventive healthcare planning

### 📄 Medical Report Generation
- Prediction reports
- Health recommendations
- Downloadable summaries

### 👤 Authentication System
- User registration
- Login management
- Secure session handling

## 📈 Model Performance

| Model | Accuracy |
|---------|---------|
| Logistic Regression | 72.56% |
| Random Forest | 70.85% |
| MLP | 72.19% |
| **XGBoost** | **73.32%** |

XGBoost achieved the highest performance and was selected as the final prediction model.
